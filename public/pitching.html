01 · ปัญหาหน้างานเดิม (Operational Pain Points)

4 จุดรั่วไหลสำคัญในการประสานงานยาราคาสูง

กระบวนการจองยาแบบเดิมที่อาศัยแชต โทรศัพท์ และไฟล์กระจัดกระจาย ก่อให้เกิดทั้งความเสี่ยงทางคลินิกและต้นทุนแฝงที่วัดมูลค่าได้ยาก

1. ยาราคาสูง & เคมีบำบัดถูกเตรียมเก้อ

ผู้ป่วย Oncology มักมีภาวะแทรกซ้อน เช่น ไข้หรือเกล็ดเลือดต่ำในวันนัด หากพยาบาลแจ้งระงับ (Hold) หรือเลื่อนวัน (Rollover) ช้า ห้องยาอาจผสมเตรียมยาล่วงหน้าไปแล้ว ทำให้ยาเสื่อมสภาพและสูญเสียทันที

ผลกระทบ: สูญเสียต้นทุนยาหลักหมื่นถึงหลักแสนบาทต่อเคส
2. ข้อมูลจองยาตกหล่น & UI ใช้งานซับซ้อน

ระบบเดิมต้องเลื่อนหาชื่อยายาวเหยียด บังคับกรอกช่องที่ไม่จำเป็น ล็อกอินร่วมแผนกไม่เสถียร และเมื่อเภสัชกรตรวจพบความผิดพลาด ไม่มี Loop ส่งกลับแก้ไขที่ชัดเจนทำให้ข้อมูลสูญหายกลางทาง

ผลกระทบ: เสียเวลาหน้างานและเกิดความเสี่ยง Medication Error
3. ยาค้างส่ง (Owings) และการยืมยาข้ามคนไข้ไร้การติดตาม

เมื่อมีการจ่ายยาไม่ครบหรือยืมยาจากคนไข้รายอื่นมาใช้ก่อน หากไม่มีระบบแจ้งเตือนแยกตามห้องยา (Phar IV, A1, E3, E6, D) และปุ่มจองคืนอัตโนมัติ มักเกิดการลืมคืนสต็อกและต้องโทรตามซ้ำ

ผลกระทบ: คลังยาสต็อกคลาดเคลื่อน และคนไข้เสี่ยงได้รับยาไม่ต่อเนื่อง
4. ใบสั่งยาตรวจยาก & ใบจัดเตรียมคลังขาดข้อมูล

เภสัชกรดูภาพสแกนใบสั่งยายากหากซูมไม่สะดวก ขณะที่คลังยาไม่มีรายงาน A4 แยกรายคนไข้ที่มีทั้ง Stock Code, จำนวน และช่องติ๊กเช็คหน้างาน ทำให้จัดยาผิดพลาดหรือกระดาษพิมพ์ตกขอบ

ผลกระทบ: คอขวดที่ขั้นตอน Verify RX และการจัดเตรียมยาในคลัง
02 · สถาปัตยกรรมระบบมาตรฐาน (REQ-01 ถึง REQ-18)

1 ระบบ 4 บทบาท: ออกแบบเฉพาะเพื่อ Workflow โรงพยาบาลจริง

เปิดหน้าแรกอัตโนมัติตามตำแหน่งงาน (Default Landing Page) พร้อมระบบ Real-time Notification และ Audit Log ทุกขั้นตอน

Role 1 · พยาบาล (Nurse)
หน้าแรก: Booking Drug
  • จองยาด่วนแบบ Minimal + Payor
  • แก้ใบจองเมื่อโดน Reject (REQ-07)
  • ยืม/จองคืนยาอัตโนมัติ (REQ-14/15)
  • รับยา Double Check & แจ้ง Hold
Role 2 · เภสัชกร (Pharmacist)
หน้าแรก: Dashboard
  • จองยาระบุห้องยา Phar Location
  • ทวนสอบ Verify RX (Scroll Zoom)
  • Approve / Reject + Note แจ้งแก้
  • อนุมัติ Cancel & ขอแก้ Stock ยา
Role 3 · คลังยา (Stock Clerk)
หน้าแรก: Dashboard
  • รับ Alert Real-time ทันทีที่จองยา
  • ไม่ต้องทวนสอบ: กดยืนยันสั่งซื้อ (1/2)
  • กดยืนยันของมาถึง (2/2) ผ่าน Shortcut Detail
  • แสดง Timestamp 1.สั่ง / 2.ถึง + พิมพ์ A4
Role 4 · ผู้ดูแล (Admin)
หน้าแรก: Dashboard
  • อนุมัติบัญชีพนักงานสมัครใหม่
  • อนุมัติคำขอแก้ไข/ลบคลังยา (REQ-16)
  • ตรวจ Audit Logs ครบทุก Action
  • Export / Archive / ล้างข้อมูล 6 เดือน
03 · ทดลองจำลองการทำงานจริง (Interactive Multi-Role Demo)

คลิกเลือกบทบาทเพื่อดูจังหวะการรับ-ส่งข้อมูลแบบ Real-time

ทุกการกดปุ่มจะสร้างสัญญาณ Alert พร้อมบันทึกเวลา (Timestamp) และชื่อผู้ดำเนินการอัตโนมัติ ลดการโทรตามงานระหว่างแผนก

พยาบาล (Nurse): หน้าจอจำลองการลงทะเบียนจองยา & แจ้งเตือน Real-time
REQ-02 · REQ-03 · REQ-09 · REQ-11
1) พยาบาล Login ด้วยรหัสประจำแผนก ระบบพาเข้าหน้า Booking Drug ทันที ไม่ต้องเสียเวลาคลิกหลายเมนู
2) พิมพ์ชื่อยา ระบบค้นหาตัวยาที่เกี่ยวข้องขึ้นมาให้อัตโนมัติ พร้อมราคาตามสิทธิ (Payor) และระบุ Note ได้
3) ทันทีที่กดบันทึก: ระบบยิง Real-time Alert + เสียงแจ้งเตือน ไปที่ Dashboard ของเภสัชกรและคลังยาทันทีโดยไม่ Lag
04 · จุดเด่นเฉพาะทางคลินิก (Clinical Safety & Zero-Waste)

ทดลองควบคุมการ HOLD ยา, เลื่อนวัน (Rollover) และยืมยาข้ามคนไข้

ทดลองสั่งระงับยาหรือปลดล็อกเคสผู้ป่วยด้านซ้าย เพื่อดูการอัปเดตสถานะและป้ายแจ้งเตือนฝั่งขวาแบบทันที

แผงควบคุมจำลองหน้างาน (Ward Action)
ยืมยาข้ามคนไข้ (REQ-14/15): เมื่อเลือกยืมยา ระบบจะ Auto-Detect รายชื่อคนไข้ที่มียาอยู่ เขียน Note ให้อัตโนมัติ และปลด Alert ทันทีเมื่อกด "จองยาคืนให้ HN ต้นทาง"
ยาทั่วไป (General) มะเร็ง (Oncology) Hold / Rollover Alert (2)
แจ้งคลังยา + เภสัชกรทันที
ผู้ป่วย (HN) รายการยาครบทุกตัว สถานะ / เหตุผล ผู้แจ้ง
Alert ล่าสุด: คลังยาได้รับแจ้งรายการระงับครบทุกตัวยาแล้ว เพื่อชะลอการจัดเตรียมล่วงหน้า
05 · เครื่องมือเพิ่มความแม่นยำสำหรับเภสัชกร & คลังยา

3 ฟีเจอร์หน้างานที่แก้คอขวดได้ตรงจุดที่สุด

ออกแบบจากการลงพื้นที่จริงของฝ่ายเภสัชกรรมและคลังเวชภัณฑ์ โรงพยาบาลกรุงเทพพัทยา

REQ-05 · REQ-06 · REQ-07

Verify RX + Mouse Scroll Zoom

  • ดูใบสั่งยาสแกนและหมุนลูกกลิ้งเมาส์ (Scroll Mouse) เพื่อย่อ-ขยายดูตัวเลขแล็บและขนาดยาได้ทันที
  • แยกหมวดหมู่ General และ Oncology ชัดเจนบน Dashboard ที่เห็นร่วมกันทุกตำแหน่ง
  • กด Approve สถานะเป็น "ยอมรับแล้ว" พร้อมชื่อเภสัชกรและเวลา
  • กด Not Approved บังคับใส่ Note เหตุผล ส่งกลับให้พยาบาลแก้โดยข้อมูลเดิมไม่สูญหาย
REQ-12 · REQ-16

ศูนย์จัดการยาค้างส่ง (Owings Desk)

  • มีตัวกรอง Pharmacy Location (Phar IV, Phar A1, Phar E3, Phar E6, Phar D) แยกความรับผิดชอบชัดเจน
  • เภสัชกร/พยาบาลติ๊กยาที่ยังไม่ได้รับเพื่อส่ง Urgent Alert ไปที่คลังยาทันที
  • Alert ทำงานต่อเนื่องจนกว่าหน้างานได้รับยาครบและกด Complete
  • การขอแก้ไข/ลบ Stock ยาโดยเภสัชกร จะส่ง Banner + Alert ให้ Admin อนุมัติก่อนมีผลจริง
REQ-13 · ปฏิทินคิว REQ-10

รายงานจัดเตรียมยา A4 ไม่ตกขอบ

  • เลือกกรองตาม Date of Use / Order Date, ช่วงวันที่, ประเภทยา และห้องยา
  • แสดง 2 ส่วนครบทั้งในหน้า Preview และหน้าพิมพ์ A4: ตารางสรุปยอดรวม + ตารางแยกรายคนไข้
  • มี ช่องติ๊กเช็คหน้างาน (☐), Stock Code ครบทุกแถว, ป้ายเตือน Hold/Rollover และยอด Qty พอดีขอบกระดาษ 100%
  • คลิกชื่อคนไข้บนปฏิทินคิวเพื่อตรวจ Location, Regimen และ Note ได้ในคลิกเดียว

07 · กรอบกลยุทธ์และตัวชี้วัดความสำเร็จ

RxNexus Lean Canvas & Target KPIs

1. PROBLEM
  • ข้อมูลจองยาเดิมสูญหาย ไม่เป็นระบบ
  • ล็อกอินรวมแผนก ขาดความปลอดภัย
  • ไม่มีแจ้งเตือน Hold / ยาค้างส่งแบบทันที
  • ค้นหายาและเช็กราคาตามสิทธิได้ช้า
2. SOLUTION
  • Cloud Database Real-time Sync
  • หน้าแรกเฉพาะ Role + RBAC ชัดเจน
  • Verify RX Scroll Zoom & Reject Loop
  • Owings Desk, Borrow Return & A4 Print
3. UNIQUE VALUE
  • จองไวในไม่กี่คลิกด้วย Auto-Suggest
  • ลดความสูญเสียยาราคาสูงได้ทันที
  • ปฏิทินคิวยา + สถานะครบจบในหน้าเดียว
  • พิมพ์ใบประเมินราคาให้คนไข้ได้ทันที
4. CHANNELS & EDGE
  • สร้างจาก Workflow จริงของรพ.
  • ใช้งานได้ทุกเครื่อง (Web + iPad/iOS)
  • ฟอนต์ Sarabun คงที่ทุกขนาดหน้าจอ
  • ครอบคลุม OPD Chemo & All Wards
5. TARGET & IMPACT
  • ผู้ป่วย Oncology & By-Case Special Meds
  • ห้องยา Phar IV, A1, E3, E6, D และคลังยา
  • ลดต้นทุนยาเสียเปล่าและเวลาคอยคิว
