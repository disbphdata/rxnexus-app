Bangkok Hospital Pattaya • Outpatient Sourcing
ฉบับฝึกอบรมพนักงาน (Standard SOP)

คู่มือการใช้งานระบบ RxNexus

ระบบบริหารจัดการการจองยา เวชภัณฑ์สำรอง และการประสานงานแบบ Real-time ระหว่างพยาบาล เภสัชกร คลังยา และผู้ดูแลระบบ (ครอบคลุมมาตรฐาน REQ-01 ถึง REQ-18)

1. พยาบาล (Nurse)
เปิดเข้าหน้าจองยาทันที • จองยาแบบรวดเร็ว • แก้ไขเมื่อถูกปฏิเสธ • ยืม/จองคืนยา • รับยา Double Check • แจ้ง Hold / Rollover / Cancel
2. เภสัชกร (Pharmacist)
เปิดเข้า Dashboard ทันที • จองยาระบุห้องยา • ทวนสอบ Verify RX (ซูมใบสั่งด้วย Scroll Mouse) • อนุมัติ/ส่งกลับพร้อม Note • จัดการยาค้างส่ง & คำขอยกเลิก
3. คลังยา (Stock Clerk)
รับแจ้งเตือน Real-time • ยืนยันรับ Order / Arrived แบบ 2 ขั้นตอน • ติดตามยาค้างจ่าย • พิมพ์ใบจัดเตรียม A4 แยกรายคนไข้พร้อมช่องติ๊กและ Stock Code
4. ผู้ดูแลระบบ (Admin)
อนุมัติบัญชีพนักงานใหม่ • อนุมัติคำขอแก้ไข/ลบคลังยา (Stock Alert) • ตรวจสอบ Audit Logs • สำรอง/กู้คืน/ล้างข้อมูลเก่า 6 เดือน
ฟอนต์มาตรฐาน: Sarabun (รองรับการแสดงผลคงที่ทุกขนาดหน้าจอและทุกเครื่องคอมพิวเตอร์) พัฒนาและออกแบบระบบ: ทีมเภสัชกรรมและระบบงาน RxNexus
Overview • REQ-01 / REQ-02 / REQ-10

ทุกตำแหน่งใช้ UI มาตรฐานเดียวกันด้วยฟอนต์ Sarabun และเข้าถึงข้อมูลแบบ Real-time

1การเข้าสู่ระบบ (Login) & หน้าแรกอัตโนมัติ (REQ-01, REQ-02)
  • พยาบาล (Nurse): Login ด้วย รหัสประจำแผนก → ระบบเปิดหน้า ลงทะเบียนจองยา (Booking Drug) เป็นหน้าแรกทันที
  • เภสัชกร (Pharmacist): Login ด้วย รหัสเฉพาะบุคคล → ระบบเปิดหน้า Dashboard เป็นหน้าแรกทันที
  • คลังยา (Pharmacy Stock Clerk): Login เข้ามา → ระบบเปิดหน้า Dashboard เป็นหน้าแรกทันที
  • การสมัครใช้งานใหม่ (Register): บัญชีใหม่จะมีสถานะรออนุมัติ ต้องรอ Admin กดอนุมัติก่อนจึงจะ Login ได้
2ปฏิทินคิวยา (Queue Calendar) — REQ-10
  • แยกแท็บและสีชัดเจน: คิวทั้งหมด / คิวยาทั่วไป (General - สีน้ำเงิน) / คิวยามะเร็ง (Oncology - สีแดง)
  • สัญลักษณ์สถานะบนปฏิทิน: ⚠️ รอยาพร้อมใช้, ✅ ยาพร้อมใช้งาน, ⏸️ HOLD, 🔄 เลื่อนวัน (Rollover)
  • คลิกที่ชื่อผู้ป่วยบนวันนั้นๆ เพื่อเปิดดู รายละเอียดยา, Stock Code, ห้องยา (Pharmacy Location), สูตรยา (Regimen) และ Note
ตำแหน่ง (Role) หน้าแรกหลัง Login หน้าที่หลักในระบบ (Core Responsibilities) ช่องทางแจ้งเตือนสำคัญ
พยาบาล (Nurse) ลงทะเบียนจองยา
(Booking Drug)		 จองยาแบบ Minimal Fields, แก้ไขใบจองเมื่อโดน Reject, ยืมยา/จองคืน, Double Check รับยา, แจ้ง Hold/Rollover/Cancel, กด Complete ยาค้างส่ง Alert เมื่อเภสัชกร Reject พร้อม Note, Alert เมื่อคลังเตรียมยา Arrived
เภสัชกร (Pharmacist) Dashboard จองยาระบุห้องยา, ตรวจทวนสอบ Verify RX (ซูมใบสั่งด้วย Scroll Mouse), กด Approve/Not Approved + Note, อนุมัติยกเลิก, ขอปรับแก้ Stock ยา Alert เมื่อมีใบจองใหม่ / ใบจองที่แก้กลับมา Re-verify / Hold / Rollover

ผู้ดูแลระบบ (Admin) Dashboard อนุมัติผู้ใช้ใหม่, อนุมัติแก้ไข/ลบรายการยาใน Stock, ตรวจ Audit Logs, Export/Import และล้างข้อมูลเก่าเกิน 6 เดือน Banner แจ้งเตือนผู้ใช้รออนุมัติ + Alert/Banner เภสัชกรขอแก้ Stock

REQ-02, REQ-03, REQ-07, REQ-11: จองไว กรอกเฉพาะข้อมูลจำเป็น ข้อมูลไม่สูญหาย และมี Loop แก้ไขชัดเจน

หน้า 3 / 11
1ขั้นตอนการจองยาโดยพยาบาล (REQ-03)
  • Login ด้วยรหัสแผนก: เข้าสู่ระบบแล้วจะอยู่ที่หน้า ลงทะเบียนจองยา ทันที
  • เลือกหมวดหมู่ยา: ยาทั่วไป (General) หรือ ยาเคมีบำบัด (Oncology)
  • กรอกข้อมูลจำเป็นขั้นต่ำ:
    1) ชื่อผู้ป่วย และ HN
    2) แผนกที่จอง (พิมพ์ค้นหาแล้วเลือกได้เลย)
    3) รายการยา (พิมพ์ชื่อยา ระบบจะแนะนำรายการที่เกี่ยวข้องอัตโนมัติ)
    4) จำนวนยาที่ใช้ และ ราคาตามสิทธิ (Payor) เช่น OPD / IPD
  • ข้อมูลเพิ่มเติม (ไม่บังคับ): ระบุ Note แจ้งรายละเอียดสำคัญ และแนบรูปสแกนใบสั่งยา (ถ้ามี)
  • ตรวจสอบ & พิมพ์ใบแจ้งราคา: กดส่งข้อมูล → ตรวจสอบรายการได้ทันทีที่ Dashboard และกดปุ่ม Print Report เพื่อพิมพ์ใบสรุปให้ผู้ป่วยตรวจสอบราคา
2กรณีจองยาผิด: Reject & Edit Loop (REQ-07)
  • รับแจ้งเตือน (Alert): เมื่อเภสัชกรตรวจพบความผิดพลาด (เช่น ผิดชนิดยา/ผิดคนไข้) เภสัชกรจะกด Not Approved พร้อมบังคับใส่ Note ระบุปัญหา
  • พยาบาลกดแก้ไข: เปิดหน้า Dashboard คลิกปุ่ม Edit บนรายการที่ถูกแจ้งเตือน → อ่าน Note จากเภสัชกร
  • อัปเดตข้อมูล: แก้ไขตัวยา จำนวน หรือ HN ให้ถูกต้อง แล้วกดปุ่ม Update
  • ส่งกลับทวนสอบซ้ำ: รายการจะเปลี่ยนสถานะกลับเป็นรอตรวจสอบที่ Dashboard พร้อมบันทึก Timestamp ให้เภสัชกรกด Verify อีกครั้ง
ข้อดีของระบบ: ข้อมูลไม่หายระหว่างทาง ไม่ต้องลบจองใหม่ทั้งหมด และมีประวัติเวลา (Timestamp) ตรวจสอบย้อนหลังได้ทุกครั้งที่แก้ไข
การแจ้งเตือนอัตโนมัติ (REQ-11): ทันทีที่พยาบาลกดบันทึกการจอง ระบบจะส่ง Real-time Alert และเสียงแจ้งเตือนไปยังหน้าจอของ เภสัชกร และ เจ้าหน้าที่คลังยา ทันทีโดยไม่ Lag

การรับยา Double Check, ยืมยาข้ามคนไข้ และปิดงานยาค้างส่ง

REQ-09, REQ-12, REQ-14, REQ-15: ตรวจรับยาปลอดภัย ติดตามยาที่ยืม และหยุด Alert เมื่อได้รับยาครบ

หน้า 4 / 11
3การรับยาและ Double Check (REQ-09)
  • สถานะพร้อมจ่าย: เมื่อคลังยากดยืนยันของมาถึงแล้ว (Ready-to-use / Arrived) จะมี Alert แจ้งมาที่พยาบาล
  • กดรับยา & Double Check: ตรวจสอบตัวยาจริงกับใบสั่งยา แล้วกดปุ่ม รับยา / Double Check บน Dashboard
  • Popup ยืนยัน: กดยืนยันในหน้าต่าง Double Check → ระบบบันทึกชื่อผู้รับยาและ Timestamp ลงใน Audit Log ทันที
4ปิดงานยาค้างส่ง (Complete Owing — REQ-12)
  • หากมีรายการยาค้างจ่ายที่คลังยาแจ้งไว้ เมื่อพยาบาลได้รับยาครบเรียบร้อยแล้ว
  • ไปที่เมนู รายการยาค้างส่ง (Owings List) → กดปุ่ม Complete (ได้รับยาครบแล้ว)
  • ผลลัพธ์: Alert แจ้งเตือนด่วนฝั่งคลังยาสำหรับเคสนี้จะ หยุดทำงานทันที
5ระบบยืมยาข้ามคนไข้ & การจองคืน (REQ-14, REQ-15)
  • การบันทึกยืมยา: ในหน้า Booking Drug เปิดสวิตช์ "ยืมยาจากคนไข้รายอื่น"
  • ตรวจจับอัตโนมัติ (Auto-Detect): เมื่อเลือกยาที่ต้องการยืม ระบบจะดึงรายชื่อคนไข้ที่มียานั้นจองอยู่ (Active Orders) มาให้คลิกเลือกได้ทันที หรือพิมพ์ HN เอง
  • บันทึก Note อัตโนมัติ: ระบบจะเขียนรายละเอียด [ยืมยา] ชื่อยา x จำนวน จาก ชื่อผู้ป่วย (HN: ...) ลงใน Note ให้อัตโนมัติ
  • การติดตามและจองคืน (REQ-15):
    • แถวของคนไข้ต้นทาง (ผู้ให้ยืม) บน Dashboard จะขึ้นป้าย ถูกยืมยาไปใช้ (รอจองคืน) พร้อมปุ่ม จองยาคืนให้ HN นี้
    • Auto-Resolve: เมื่อกดจองยาใหม่ให้ HN ต้นทางด้วยรายการยาที่ตรงกัน ระบบจะปลดสถานะเป็น "คืนแล้ว" และลบ Alert ค้างคืนให้อัตโนมัติ

การแจ้ง Hold, เลื่อนวันใช้ยา (Rollover) และขอยกเลิก (Cancel)

REQ-17, REQ-18: ป้องกันการผสมยาหรือเตรียมยาเกินความจำเป็น พร้อมแจ้งเตือนเภสัชกรและคลังยาทันที

หน้า 5 / 11
Aระงับชั่วคราว (HOLD)
  • ใช้เมื่อผู้ป่วยมีไข้ ผลเลือดไม่ผ่าน หรือแพทย์สั่งชะลอการให้ยา
  • กดปุ่ม Hold บน Dashboard → กรอก เหตุผล และ ชื่อพยาบาลผู้แจ้ง
  • ระบบแจ้ง Alert ถึง คลังยา + เภสัชกร ทันที พร้อมชื่อ-สกุล, HN, รายการยาครบทุกตัว, เหตุผล และ Timestamp
  • เมื่อพร้อมให้ยาต่อ กดปุ่ม Continue / Unhold เพื่อคืนสถานะปกติ
Bเลื่อนวันใช้ยา (Rollover)
  • ใช้เมื่อผู้ป่วยเลื่อนนัดรับยาไปวันอื่น
  • กดปุ่ม Rollover → เลือก วันที่ใช้ยาใหม่ + ระบุเหตุผล + ชื่อพยาบาลผู้แจ้ง
  • รายการยาจะย้ายไปแสดงบน ปฏิทินวันใหม่ พร้อมป้าย 🔄 เปลี่ยนวัน + Timestamp
  • ระบบแจ้ง Alert ถึงคลังยาและเภสัชกรทันที พร้อมส่งสถานะกลับมา Verify ใหม่ตามวันนัดใหม่
Cขอยกเลิก (Cancel Request)
  • ใช้เมื่อแพทย์สั่งหยุดยา/ยกเลิกคอร์สการรักษา
  • กดปุ่ม Cancel → ระบุ เหตุผลการยกเลิก
  • ระบบส่ง Alert คำขอยกเลิก ไปหาเภสัชกร/Admin และคลังยาทันที พร้อมรายละเอียดผู้ป่วยและรายการยา
  • เมื่อเภสัชกร/Admin กดอนุมัติยกเลิก คลังยาจะได้รับ Alert แจ้งยกเลิกสมบูรณ์ทันที
หลักสำคัญหน้างาน: หากมีการเปลี่ยนแผนการรักษา (Hold / Rollover / Cancel) ให้กดแจ้งใน RxNexus ทันที เพื่อป้องกันความสูญเสียของยาเคมีบำบัดหรือยาราคาสูงจากการเตรียมผสมล่วงหน้า

REQ-02, REQ-04, REQ-05, REQ-06, REQ-07: จัดการคิว Dashboard ซูมใบสั่งยา และอนุมัติ/ส่งกลับ

  • ข้อมูลจำเป็นที่ต้องกรอก:
    • ชื่อผู้ป่วย, HN, แผนกที่จอง
    • ห้องยาที่ใช้ยา (Pharmacy Location) — บังคับเลือก (เช่น Phar IV, Phar A1, Phar E3, Phar E6, Phar D)

2การทวนสอบผ่าน Dashboard & Verify RX (REQ-05)
  • แยกหมวดหมู่ชัดเจน: Dashboard แสดง 2 หมวดให้ทุก User เห็นร่วมกันคือ 1) รายการจองยาทั่วไป และ 2) รายการจองยา Oncology
  • ซูมใบสั่งยา (Mouse Wheel Zoom): เมื่อคลิกเปิดดูรูปใบสั่งยาในหน้า Verify RX หรือ Modal รูปภาพ สามารถ หมุนลูกกลิ้งเมาส์ (Scroll Mouse) เพื่อย่อ-ขยายดูรายละเอียดได้ทันที
  • กรณีถูกต้อง (Approve — REQ-06): กดปุ่มทบทวนสำเร็จ → สถานะเปลี่ยนเป็น "ยอมรับแล้ว" พร้อมแสดงชื่อ Pharmacist ผู้อนุมัติและ Timestamp
  • กรณีไม่ถูกต้อง (Not Approved — REQ-07): กดปุ่มทบทวนไม่ผ่าน → ระบบบังคับกรอก Note ระบุปัญหา → ส่ง Alert กลับไปยังผู้จองให้ Edit → Update กลับมาให้ Verify ใหม่

5อนุมัติยกเลิก (REQ-18)

  • ตรวจสอบความถูกต้องแล้วกด Approve Cancel (หรือ Reject พร้อม Note)
  • เมื่ออนุมัติแล้ว ระบบจะแจ้ง Alert ไปยัง คลังยา ทันที

    2) ตารางรายละเอียดแยกรายคนไข้ (Individual Allocations): มีช่อง ☐ สำหรับติ๊กเช็คหน้างาน, ลำดับ, HN, ชื่อผู้ป่วย (พร้อมป้าย Hold/Rollover), วันที่ต้องใช้, ชื่อยา, Stock Code และ Qty

4การติดตาม Hold, Rollover และ Cancel (REQ-17, REQ-18)

  • กรณี Rollover: ได้รับ Alert แจ้งวันเดิม → วันใหม่ พร้อมรายการยาและ Timestamp
  • กรณี Cancel: ได้รับ Alert ทั้งตอนพยาบาลส่ง ขอยกเลิก และตอนเภสัชกร/Admin อนุมัติยกเลิก เพื่อหยุดการจัดซื้อหรือดึงยากลับเข้าสต็อกทันที
